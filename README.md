# 🛋️ Furni-Hub | Premium Furniture E-commerce Platform

**Furni-Hub** is a modern, full-stack e-commerce platform designed to showcase and manage premium furniture collections. Built with **Next.js** and the **MERN Stack**, it offers a seamless experience for both users and administrators.

**🌐 Live Demo:** [https://furni-hub-six.vercel.app/](https://furni-hub-six.vercel.app/)

---

## 🚀 Key Features

* **Premium UI/UX:** A clean, minimalist aesthetic tailored for luxury furniture brands, ensuring a visually stunning experience.
* **Dynamic Product Management:** Integrated Admin Dashboard to effortlessly add, update, and manage the product catalog.
* **Fully Responsive:** 100% optimized for mobile, tablet, and desktop views using Tailwind CSS.
* **Secure Authentication:** Protected routes and session management powered by NextAuth.js.
* **Advanced Tech Stack:** High-performance rendering with Next.js and real-time data storage with MongoDB.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React.js, Tailwind CSS
* **Backend:** Next.js API Routes, Node.js
* **Database:** MongoDB with Mongoose/Native Driver
* **Authentication:** NextAuth.js
* **Icons:** Lucide-React
